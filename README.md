## ◈ Hi, I'm Augustine

I build the data plumbing that finance teams depend on. Most of my work sits in the part of a data system you only notice when it breaks: database clusters, Spark jobs, Kafka streams, and SQL that has to give the same answer after a migration.

I started out building credit risk models, so I still ask how the data will be used before I decide how to move it.

I'm looking for **Senior Data Engineer** roles on market or financial data platforms. Over time I'd like to take on Staff-level work: platform design and the standards other teams build on.

📖 The longer version, with project write-ups and how I'd approach a platform, is on [**my site**](https://augustine0890.github.io).

## ◈ Habits I Bring to Financial Data

- Keep event time and arrival time apart, so a backtest never sees tomorrow's data.
- Fix reference data first. A bad symbol mapping does more damage than a slow query.
- Make every pipeline safe to run twice.
- Check against the source before anyone downstream sees the numbers.
- Write the design decision down, including what would make us reverse it.
